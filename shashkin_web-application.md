**[ НАЗВАНИЕ ПРОЕКТА ]**

Expirely

**[ ПРОБЛЕМНОЕ ПОЛЕ ]**

API-ключи, SSL-сертификаты, токены доступа и домены имеют ограниченный срок действия. При их истечении сервисы перестают работать: падают интеграции, ломается доступ к API, перестаёт работать почта и веб-сайты.  
Ручное отслеживание сроков в таблицах Excel или календарях ненадёжно и плохо масштабируется.  
Существующие решения (HashiCorp Vault, Azure Key Vault и др.) чаще всего избыточны и сложны для небольших команд и индивидуальных разработчиков.  

Expirely решает эту проблему: позволяет централизованно хранить информацию о сроках действия важных сущностей и автоматически отправлять уведомления по электронной почте до их истечения.

**[ ЗАКАЗЧИК / ПОТЕНЦИАЛЬНАЯ АУДИТОРИЯ ]**

- Небольшие IT-команды и стартапы
- Системные администраторы

**[ АППАРАТНЫЕ / ПРОГРАММНЫЕ ТРЕБОВАНИЯ ]**

- Любая современная операционная система (Windows, Linux, macOS)

- Node.js 18+
- Доступ в интернет (для отправки уведомлений)

**[ ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ ]**

Продукт будет предоставлять следующие возможности:

- Добавление записей (название, дата истечения, email для уведомления)
- Просмотр списка всех записей
- Редактирование записей
- Удаление записей
- Ручная проверка сроков («Проверить сейчас»)
- Автоматическая проверка по расписанию
- Отправка email-уведомлений за 30 / 7 / 3 дня до истечения и при просрочке
- Просмотр статистики (сколько записей скоро истекает / уже просрочено)
- Логирование отправленных уведомлений

**[ ПОХОЖИЕ / АНАЛОГИЧНЫЕ ПРОДУКТЫ ]**

- HashiCorp Vault / Azure Key Vault — мощные enterprise-решения, избыточные для небольших команд
- Различные self-hosted expiry-трекеры — часто требуют сложной настройки
- Простые таблицы + календарь — не автоматизируют уведомления

Expirely позиционируется как лёгкое и понятное решение «установил и работает» для небольших команд и индивидуальных разработчиков.

**[ ИНСТРУМЕНТЫ РАЗРАБОТКИ, ИНФОРМАЦИЯ О БД ]**

- Backend: Node.js + Express
- База данных: SQLite (better-sqlite3)
- Отправка писем: Nodemailer
- Frontend: HTML + CSS + Vanilla JavaScript
- Система контроля версий: Git + GitHub

**[ ВОЗМОЖНЫЕ РИСКИ ]**

- Проблемы с отправкой писем через Gmail (блокировка SMTP) → использование App Password или переход на другой SMTP-сервис
- Нехватка времени на реализацию всех запланированных функций → приоритизация: сначала стабильный backend + уведомления, потом расширение функционала

- Ошибки при работе с базой данных → тщательное тестирование CRUD-операций
